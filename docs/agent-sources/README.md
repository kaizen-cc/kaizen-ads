# Agent sources

Exports of Kaizen's Claude projects (instructions + knowledge files), taken 2026-10-15, and the condensed plans
that were loaded into the app's agents (`plans/`). The database (Settings → AI agents) is the source of truth
after loading: a few items were adjusted at load time (Kyle's 3 short + 2 long copy format, no auto-approval in the
Brand Bible, Limelight prices from the website). Re-import a project by exporting it again and condensing it the
same way; don't paste whole files into a playbook, since every agent reads its playbook on every call.
